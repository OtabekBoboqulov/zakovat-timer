# Zakovat Timer

A highly aesthetic and immersive timer web application designed for the "Zakovat" intellectual game. It features a modern, space-themed UI with glassmorphism elements and smooth animations.

## Features

- **Three Timer Modes**:
  - **Standard**: 60-second main timer followed by a 10-second final countdown.
  - **Dublet**: Two consecutive 30-second rounds with a transition in between, followed by a 10-second final countdown.
  - **Blits**: Three consecutive 20-second rounds with transitions, followed by a 10-second final countdown.
- **Immersive Mode**: The UI automatically hides all distractions (titles, menus, etc.) when the timer is running, focusing solely on the countdown. Everything returns once the timer sequence completes.
- **Interactive Controls**:
  - **Pause/Resume**: Click directly on the timer circle to pause or resume the countdown.
  - **Suspend**: A dedicated "Suspend" button appears during the timer to allow for immediate reset to the main menu.
- **Visuals & Sound**:
  - **Night Sky Background**: Animated stars and gradients for a premium look.
  - **Glassmorphism**: Modern UI components with blur and transparency.
  - **Audio Feedback**: Subtle ticking sound during the countdown and a dramatic bell chime when time is up.

## How to Use

1. Open `index.html` in any modern web browser.
2. Select one of the three modes: **Start** (Standard), **Dublet**, or **Blits**.
3. The timer will start immediately, and the UI will enter Immersive Mode.
4. Click the timer circle to pause/resume.
5. In Dublet or Blits mode, after each round, a pulsing Play button will appear to transition to the next round.
6. Use the **Suspend** button at the bottom if you need to abort the timer and return to the menu.

## Technologies Used

- HTML5
- CSS3 (Animations, Flexbox, Transitions)
- Vanilla JavaScript
- Web Audio API (for sound generation)
